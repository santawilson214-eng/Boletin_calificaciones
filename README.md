Descripción

Aplicación de Windows Forms en C# que calcula el promedio de cada asignatura de un estudiante, determina su situación académica y muestra un resumen general.

Funcionamiento

1. Se escribe el nombre del estudiante y se elige su tanda (matutina o vespertina).
2. Se selecciona una asignatura: Matemática, Lengua Española, Ciencias Naturales, Inglés o Informática.
3. Se ingresan las calificaciones de los 4 períodos (de 0 a 100) y se indica si cumple la asistencia mínima (80 %).
4. Registrar asignatura agrega al boletín la asignatura con su promedio y situación.
 5.  Mostrar resumen presenta el promedio general, las cantidades de asignaturas aprobadas, en recuperación y reprobadas, y la situación general.
6. Limpiar deja el formulario como al iniciar y Salir cierra la aplicación.
